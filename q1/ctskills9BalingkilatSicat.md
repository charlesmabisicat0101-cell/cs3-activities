## Computational Thinking Concepts Applied in CS

### 1. Problem Decomposition
Breaking down complex tasks into smaller, manageable components:
* Separating major software requirements into modular functions and routines.
* Dividing software tasks among development team members.

### 2. Pattern Recognition
Recognizing recurring structures and solutions:
* Identifying common logical loops and data handling patterns across different scripts.
* Reusing proven logic structures to handle data arrays, lists, and dictionaries.

### 3. Abstraction
Representing information effectively while filtering out unnecessary details:
* Utilizing data structures like lists, dictionaries, objects, and JSON to organize information.
* Hiding complex implementation layers behind clean function interfaces.

### 4. Algorithm Design
Developing step-by-step solutions:
* Formulating precise operational sequences using control structures.
* Designing clear program execution paths tested for efficiency and readability.
